# Seedance

Gerador de video com IA (Seedance 2.5, via Atlas Cloud). Um arquivo, sem dependencias.

- Local: `python3 seedance.py --web` e abrir http://127.0.0.1:8777
- Linha de comando: `python3 seedance.py texto "sua cena"`

Variaveis: `ATLASCLOUD_API_KEY` (obrigatoria), `SEEDANCE_SENHA` (obrigatoria na
internet), `SEEDANCE_SALVAR_LOCAL=0` para nao gravar em disco.
